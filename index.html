Image Slider Library

A responsive image slider built with HTML, CSS, and vanilla JavaScript.

About This Slider

This image slider is developed using vanilla JavaScript without third-party carousel libraries. It uses CSS transforms and transitions to create smooth horizontal image movement.

Responsive

The slider automatically adapts to different screen sizes and devices.

Infinite Loop

Users can continuously move through all images without reaching an endpoint.

Interactive

Users can navigate using the previous and next buttons or navigation dots.
